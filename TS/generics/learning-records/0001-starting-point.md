# Starting point: recognises generics, has not written one

The user has seen generic call sites like `Array<T>` and `useState<T>` but can't yet write their own generic function. Their goals are reading real codebases, writing reusable code, and levelling up for interviews. Start at "declare a type parameter + inference"; don't assume constraints or `keyof` yet.

**Evidence**: self-reported in the onboarding questions (2026-10-19).
